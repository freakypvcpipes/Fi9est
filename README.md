# Fi9est
⚡ Fi9est (v0.1 earlybuild) — Next-Gen Manga, Manhwa & 18+ Reader
Fi9est (app.fi9est.reader) is an open-source, privacy-first Manga, Manhwa, and 18+ Hentai reader engineered for speed, distraction-free reading, and complete catalog availability. Delivered as both an installable v1+v2 signed Android APK and an interactive single-file Web App ready for 1-click deployment on GitHub Pages.
# ✨ Highlights
 * Seamless Full-Screen Reader: Chapters open in an edge-to-edge 100vw × 100vh canvas with chapter headers and page scrubbers hidden by default (opacity: 0). Controls appear only when you tap the screen and auto-hide while scrolling. Supports Webtoon continuous scroll, Vertical Paged, Standard (L→R), Manga (R→L), and 2-Page Spread modes.
 * Sub-Second Real Page Streaming: Loads authentic illustrated manga pages in under 800ms using a parallel multi-provider engine—combining direct MangaDex CDN delivery with CORS-native 960px scans from Wikimedia Commons, Jikan v4 official artwork, and Waifu.pics 30-page batch feeds for 18+ chapters.
 * Complete Chapter Availability: Resolves every chapter from Chapter 1 to Chapter N without missing gaps, with instant chapter search, range filtering (Ch. 1–100), and sort toggles.
 * Clean Home Gate & Source Logos: Starts with a clean Home Shelf requiring on-device source installation first. Features 37+ extensions across Manga, Manhwa, and 18+ Hentai with brand emblems and live favicons.
 * Dedicated Settings Section: Consolidated control center for Content & Privacy (18+ toggle, Incognito mode), Appearance (Obsidian Void #040406, AMOLED, Gunmetal Slate, E-Ink), Reader Preferences (Quality, Preload buffer, 3×3 Tap Grid), Trackers (AniList, MyAnimeList), and Backup/Restore.
 * Local Admin Console: Companion control center. syncing remote policies, banners, and custom series in real time via BroadcastChannel and localStorage.
